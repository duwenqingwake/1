# 本地量化研究工具

面向面试展示的 Python 桌面研究工具。包含可离线查看的历史研究案例、基于 BaoStock 的单股票回测，以及因子研究模块。项目使用 AI 辅助开发。

## 使用方式

Windows 免安装版：下载 Release 中的 ZIP，完整解压后双击 `量化研究工具.exe`。不要单独移动 EXE；依赖、演示数据需保留在同目录。

源码版（Windows，建议 Python 3.13）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/面试演示.py
```

## 模块

| 模块 | 功能 | 网络需求 |
| --- | --- | --- |
| 研究案例 | 主板小市值轮动与收盘止损8%，展示历史净值、回撤和绩效 | 离线 |
| 股票策略回测 | 单股票均线趋势、放量突破，参数设置及交易明细 | BaoStock在线接口 |
| 因子测试 | 历史因子示例；在线计算因子与分组表现 | 示例离线，新计算联网 |

## 研究报告

[阅读止损8%研究报告](reports/主板小市值轮动_收盘止损8研究报告_面试版.pdf)

案例区间为2023-01-03至2026-09-24，初始资金10万元，历史模拟收益276.56%，最大回撤31.10%。这是既往模型的研究示例，不是实盘业绩，也不是当前GUI重新计算的结果。

信号与8%止损均在收盘后确定，下一交易日开盘尝试成交；不属于盘中触发8%止损。触发阈值不能保证成交亏损不超过8%。估算流通市值、公告标题风险识别、公司行动和成交假设均存在限制；最多5只持仓不等于单股最多20%。完整限制见报告。

附带因子结果是历史示例，不能证明样本外预测能力。在线因子研究依赖行情覆盖和历史状态字段，费用口径与策略案例须分别核对，不作为比赛正式成绩。工具不含自动下单、券商账户或交易凭证。

## 数据与文件

- `src/`：可阅读、修改的Python源码。
- `演示数据/`：脱离开发机可读取的案例统计与交易结果，不包含全市场行情数据库。
- `reports/`：研究报告PDF和Word版。
- `第三方许可/`：依赖许可说明；依赖完整许可另见各自发行包。
- `运行结果/`：首次运行自动创建，用于新结果和API缓存，不纳入仓库。

在线行情使用BaoStock公共接口，不需要个人账户或API密钥；网络失败会影响新回测。研究结果只用于能力展示，不能视为投资建议或保证收益。使用可写目录运行。

## 自检

```powershell
python src/面试演示.py --self-test
```

此检查验证三个页面及离线示例加载，不代表在线接口可用或全部金融模型正确。在线功能另受第三方服务可用性影响。
